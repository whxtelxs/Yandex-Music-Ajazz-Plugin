# Spotify / Yandex Music Ajazz Plugin 2.1.0

Плагин для локального управления Spotify и Яндекс Музыкой с помощью Ajazz APK05, AKP153 и других устройств StreamDock. Spotify Web API, OAuth и ключи разработчика не используются.

## Что нового в 2.1.0

- Добавлены отдельные actions **Запуск Spotify** и **Запуск Яндекс Музыки**.
- Активное приложение можно менять прямо с устройства StreamDock: назначьте две launch-кнопки на разные клавиши и переключайтесь нажатием, без открытия веб-настроек.
- Для Spotify и Яндекс Музыки используются разные CDP-порты: `9233` и `9222`.
- Один набор кнопок управления можно использовать для выбранного приложения.
- Добавлен режим установки двух плагинов одновременно с уникальными action UUID.
- Обновлены описание, branding и изображения плагина.

## Какой вариант выбрать

### Один плагин для двух приложений

В панели настроек откройте раздел **Соединение** и выберите приложение:

- **Spotify** — локальный CDP-порт `9233`.
- **Яндекс Музыка** — локальный CDP-порт `9222`.

Порт назначается автоматически, вручную его менять не нужно. В веб-интерфейсе можно выбрать приложение и нажать **Запустить выбранное приложение**.

Для переключения без открытия настроек назначьте на две клавиши StreamDock actions **Запуск Spotify** и **Запуск Яндекс Музыки**. Нажатие нужной клавиши запустит приложение с правильным портом и сделает его активным для остальных кнопок управления.

### Два плагина одновременно

Можно установить оба каталога в папку StreamDock `plugins`:

```text
com.whxtelxs.streamdock.spotifymusic.sdPlugin
com.whxtelxs.streamdock.yandexmusic.sdPlugin
```

В этом режиме выберите отдельные actions из категорий Spotify и Yandex Music. Spotify использует `9233`, Яндекс Музыка — `9222`; приложения и плагины не должны использовать один и тот же CDP-порт. Для переключения между ними используйте две отдельные launch-кнопки.

## Возможности

### Кнопки
- **Плей/Пауза** - воспроизведение и пауза трека
- **Следующий/Предыдущий трек** - переключение треков
- **Лайк/Дизлайк** - оценка текущего трека с отображением состояния
- **Случайный порядок** - включение и выключение shuffle с отображением состояния на кнопке
- **Повтор** - переключение режима повтора (выкл → список → один трек), иконка соответствует текущему режиму
- **Громкость + / Громкость −** - шаг изменения громкости настраивается в панели свойств (1–99%, по умолчанию 5%)
- **Выключить звук** - mute/unmute с отображением состояния
- **Обложка трека** - обложка текущего трека; нажатие - плей или пауза
- **Название трека** - бегущая строка формата "Артист - Название"
- **Время трека** - текущее время / общая длительность
- **Запуск Spotify** - запускает Spotify с CDP-портом `9233` и делает Spotify активным приложением
- **Запуск Яндекс Музыки** - запускает Яндекс Музыку с CDP-портом `9222` и делает Яндекс Музыку активным приложением

### Энкодеры (Крутилки)
- **Громкость (Энкодер)** - вращение: изменение громкости, нажатие: mute/unmute
- **Перемотка (Энкодер)** - вращение: перемотка трека, нажатие: плей/пауза
- **Треки (Энкодер)** - вращение: следующий/предыдущий трек, нажатие: плей/пауза

### Состояния и синхронизация

- Состояние Play/Pause отображается на кнопке.
- Состояние лайка, mute, shuffle и repeat синхронизируется с приложением.
- Название, исполнитель, обложка и время трека обновляются автоматически.
- При разрыве CDP-соединения плагин пытается переподключиться.
- Настройки шага громкости и размеров текста сохраняются между запусками.

## Установка

<details>
<summary>Windows</summary>

1. Скачайте релиз и распакуйте папку по пути 
  ```
C:\Users\USERNAME\AppData\Roaming\HotSpot\StreamDock\plugins
  ```

2. Запустите StreamDock.
3. Добавьте на APK05 actions из категории **Spotify / Yandex Music**.
4. Назначьте **Запуск Spotify** и **Запуск Яндекс Музыки** на две отдельные клавиши.
5. Нажмите нужную launch-кнопку: настройки для переключения приложения открывать не нужно.

Если Spotify уже запущен без debug-порта, кнопка запуска полностью перезапустит его с портом `9233`. Не запускайте одновременно два Spotify-процесса вручную.


</details>

<details>
<summary>MacOS</summary>

1. Скачайте релиз и распакуйте папку по пути 
  ```
Библиотека - Application Support - HotSpot - StreamDock - plugins
  ```


2. Откройте настройки плагина и выберите нужное приложение или назначьте две launch-кнопки.
3. Запустите нужное приложение и настройте кнопки.


</details>

## Настройка энкодеров

Для устройств с крутилками (например, Ajazz AKP05):

1. Откройте StreamDock и перейдите во вкладку **Knob**
2. Найдите категорию **Spotify / Yandex Music**
3. Перетащите нужный энкодер на крутилку устройства:
   - **Громкость (Энкодер)** - управление громкостью
   - **Перемотка (Энкодер)** - перемотка и плей/пауза
   - **Треки (Энкодер)** - переключение треков и плей/пауза

## Быстрый сценарий использования

1. Назначьте обычные actions управления на нужные кнопки APK05.
2. Назначьте **Запуск Spotify** и **Запуск Яндекс Музыки** на две свободные кнопки.
3. Нажмите кнопку нужного приложения.
4. Используйте тот же Play/Pause, Next, Previous, энкодеры и остальные controls: они работают с последним выбранным приложением.

## Проверка соединения

Проверьте статус соединения, нажав на любую кнопку, а затем на "Проверить соединение"


> ⚠️ Для Spotify используется `9233`, для Яндекс Музыки `9222`. При использовании одного плагина порт выбирается автоматически. При использовании двух плагинов оставьте оба приложения на своих отдельных портах.
